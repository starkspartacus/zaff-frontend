# Composants Magic UI

Réécrits d'après l'API publique de [Magic UI](https://magicui.design) (licence MIT) sur `framer-motion`,
le site n'étant pas joignable depuis l'environnement de développement. Mêmes noms et mêmes props
que l'original : on peut les remplacer par la version officielle avec
`npx shadcn@latest add "https://magicui.design/r/<composant>.json"`.

| Composant | Usage dans ZAFF |
|---|---|
| `AnimatedList` | toasts et centre de notifications temps réel |
| `NumberTicker` | chiffres clés (CA du jour, ventes, appareils en stock) |
| `BlurFade` | apparition des cartes et écrans de résultat |
| `BorderBeam` | carte produit en attente de confirmation de vente |
| `AnimatedShinyText` | badges « En direct » |
